# Blog Content Log — Global Careers by Testbook

This log tracks blog articles published to the Global Careers blog. Posts live in the
Supabase `blog_posts` table (publishing = inserting a row with `published=true`); the
site reads them at **/#/blog** and **/#/blog/&lt;slug&gt;**. This file is a human-readable
record for planning and de-duplication — it is **not** the source of truth (the database is).

- **Author:** Global Careers by Testbook

- **Cadence:** one post per day
- **Block types supported by the renderer:** `lead, h2, p, quote, stat, stats, list, callout` only
  (no h3/table/image, and no clickable links inside body text — related articles are referenced by title in prose)

  point readers to official sources for specifics.
